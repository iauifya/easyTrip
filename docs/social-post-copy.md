### 02 為什麼做這個專案

主標：
旅行最累的，常常不是玩

內文：
而是一直確認：
下一站去哪裡？
幾點要出發？
路程會不會太趕？
今天的行程到底走到哪了？

EasyTrip 想解決的，就是這些旅途中細碎但真實的焦慮。

畫面建議：
左側放 3-4 個旅行中的小困擾，右側放 EasyTrip 的簡潔行程畫面。

### 03 特色一：每日行程清楚排好

主標：
把一天拆成看得懂的節奏

內文：
使用者可以依日期安排景點、餐廳、交通、購物、休息等不同類型的停留點。

每個停留點都有時間、停留長度、備註與地點資訊，行程不是一張雜亂清單，而是一條清楚的旅行時間線。

畫面建議：
使用 Day Plan 畫面，標出時間線、類別標籤、停留時間。

---

### 04 特色二：Google Maps 連動

主標：
貼上 Google Maps 連結，就能整理地點資訊

內文：
EasyTrip 以 Google Maps URL 作為主要地點來源，協助解析地點名稱、地址、座標與 Google Place ID。

這讓路線估算更精準，也避免只靠文字地址時，跑到相似名稱的錯誤地點。

畫面建議：
放新增地點表單與地圖預覽，視覺上強調「貼上連結 -> 自動補齊」。

---

### 05 特色三：路線預估與移動提醒

主標：
不只知道去哪，也知道怎麼接下一站

內文：
Route Preview 會依照每日停留點產生移動概覽，並透過 Google Routes API 預估相鄰景點之間的步行時間與距離。

使用者可以快速判斷：
這段會不會太遠？
中間有沒有時間緩衝？
要不要直接打開 Google Maps 導航？

畫面建議：
使用 Route Preview 區塊，標示站點數、路段數、移動時間、Google Maps 導航按鈕。

---

### 06 特色四：Today Mode

主標：
旅行當下，只看現在最重要的事

內文：
Today Mode 會聚焦在「下一站」與「目前進度」。

它會顯示下一個停留點、建議行動、出發或停留提醒、移動時間、今日完成進度，讓使用者不用在完整行程裡反覆翻找。

畫面建議：
使用深色 Today Mode 畫面，放大下一站卡片與進度條。

---

### 07 設計巧思

主標：
介面安靜，但該提醒的地方不沉默

內文：
EasyTrip 的 UI 採用台灣感的配色與俐落框線，讓畫面有旅遊溫度，但不過度裝飾。

當行程太滿、時間太長、轉場太緊時，系統會用醒目的提醒卡片提示，讓使用者在出發前就能調整節奏。

畫面建議：
展示警示卡片、節奏選擇、台灣風格配色。可用小標籤標出「calm UI」「pace warning」「mobile-first」。

---

### 08 技術與總結

主標：
一個從產品體驗到工程結構都完整的 MVP

內文：
EasyTrip 使用 Next.js、React、TypeScript、Tailwind CSS、Zustand、React Hook Form、Zod 與 Vitest 建置。

核心邏輯拆分在 lib 層，包含時間計算、行程排序、今日狀態、路線估算與 localStorage 儲存，讓功能可以被測試、維護與持續擴充。

結尾句：
EasyTrip 讓旅行規劃不只停在出發前，而是一路陪你走到下一站。

畫面建議：
左側放技術棧，右側放產品畫面拼貼。最後加上網址或 QR code。

## 貼文 Caption

EasyTrip 是一個為城市小旅行設計的行程規劃 MVP。

很多旅行工具都能把景點收藏起來，但真正出門後，我們常常需要的是更即時、更清楚的答案：

下一站是哪裡？
現在該出發了嗎？
這段路會不會太趕？
今天的行程進度到哪裡了？

所以我在 EasyTrip 裡做了幾個重點：

- 每日行程時間線：用日期、時間、類別與停留長度整理一天的節奏
- Google Maps 連動：貼上地圖連結後解析地點資訊，讓地址與路線估算更可靠
- Route Preview：預估相鄰停留點之間的步行時間與距離
- Today Mode：旅行當下只聚焦下一站、移動時間與今日進度
- 行程節奏提醒：當景點太多、時間太長或轉場太緊時，主動提醒使用者調整

設計上，我希望它看起來有台灣城市旅行的溫度，但使用起來仍然安靜、清楚、不干擾。

技術上使用 Next.js、React、TypeScript、Tailwind CSS、Zustand、React Hook Form、Zod、Vitest，並整合 Google Maps Platform 的 Places API 與 Routes API。

EasyTrip 想做的不是取代旅行的驚喜，而是把那些會讓人分心的小焦慮先整理好，讓使用者可以更安心地走向下一站。

## 短版貼文文案

EasyTrip 是一個為城市小旅行設計的行程規劃工具。

它不只幫你排行程，也會在旅行當下提醒下一站、移動時間、今日進度與可能過緊的安排。

核心功能包含：

- 每日行程時間線
- Google Maps 地點解析
- 路線時間與距離預估
- Today Mode 當日旅行模式
- 行程節奏與緊湊提醒
- local-first 儲存與響應式介面

我希望它像一個安靜的旅行助手：不搶走旅程本身的風景，只在你需要方向時，剛好把下一步說清楚。
